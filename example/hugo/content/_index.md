This is a demo of **markdown-blocks** — block-level in-browser editing for static sites.

Click on any block below to edit it inline. Changes are saved directly to your Markdown source files.

## Features

- Edit paragraphs, headings, lists inline
- Reorder blocks with move up/down buttons
- Insert new blocks between existing ones
- Delete blocks you don't need
- All changes persist in your source files

## How It Works

1. Start Hugo's dev server: `hugo server`
2. Start the markdown-blocks save server as a proxy
3. Browse to `http://localhost:8765/` — that's the save server, not Hugo directly
4. Click on any content block to start editing
