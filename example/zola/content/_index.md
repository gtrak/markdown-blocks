Welcome to the markdown-blocks Zola demo. This page shows how inline editing works with Zola's dev server and the markdown-blocks save server.

## Features
- Edit any heading or paragraph by clicking it
- Changes are saved back to your `.md` files in real time
- Works through a proxy between your browser and Zola's dev server
